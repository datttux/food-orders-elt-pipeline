2. WHAT DOES EACH PYTHON FILE DO? (IN SIMPLE WORDS)
--------------------------------------------------------------------------------
1. config.py            : Settings notebook (database password, paths, batch size).
2. extract.py           : The Reader. Reads the CSV 100 rows at a time.
3. load_raw.py          : The Safe. Saves raw data into MySQL without changing anything.
4. retrieve_raw.py      : The Fetcher. Pulls batches from the raw database.
5. transform.py         : The Cleaner & Calculator. Removes duplicates, labels 
                          missing info, and calculates profit and delivery duration.
6. validate.py          : The Inspector. Makes sure no mistakes or negative times exist.
7. load_transformed.py  : The Final Storer. Puts clean data into the analytics database.
8. elt_batch_pipeline.py: The Conductor. Runs all steps in sequence from start to finish.
9. sql_analysis.py      : The Analyst. Runs SQL questions to give management clear answers.


3. WHY DO WE USE TWO SEPARATE DATABASES? (ELT PRINCIPLE)
--------------------------------------------------------------------------------
• Database 1 (Raw)      : If business rules change in the future, your original 
                          data is never lost or destroyed.
• Database 2 (Analytics): Fast, clean, reliable data ready for business charts,
                          reports, and dashboards without data bugs.
